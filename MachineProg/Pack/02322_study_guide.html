1  Number Representation

1.1  Two's Complement

Core idea With n bits, the top bit is the sign (1 = negative). A positive number is just plain binary. To get the negative of any value: invert all bits, then add 1. The range of an n-bit value is −2n−1 … +2n−1−1.
Method — convert decimal to n-bit 2's complement
  1. Write +|value| as a plain binary number padded to n bits.
  2. If the original number was positive → done.
  3. If negative → flip every bit (0↔1), then add 1.
F2023 Q1a — Given +234 = 0011101010 (10-bit), find −234

The fastest route is to negate the given representation directly (invert + add 1):

+234 = 0011101010
invert  1100010101
add 1 = 1100010110

Answer: 1100010110

F2023 Q1b — −127 in 8 bits
+127 = 0111 1111
invert  1000 0000
add 1 = 1000 0001

Answer: 1000 0001. (Note: −128 = 1000 0000 is the most-negative 8-bit value.)

F2024 Q1c — −23 in 8 bits
+23  = 0001 0111
invert  1110 1000
add 1 = 1110 1001

Answer: 1110 1001

E2020 Q1a/b — +86 and −86 in 8 bits
+86  = 0101 0110            (64+16+4+2)
-86 : invert 1010 1001
      add 1  1010 1010

+86 = 0101 0110  ·  −86 = 1010 1010

1.2  Binary ↔ Hexadecimal

Method Group the bits into nibbles of 4 from the right. Each nibble is one hex digit (0000=0 … 1010=A … 1111=F). Going the other way, expand each hex digit into 4 bits.
F2024 Q1b — 1100000011011110 to hex
1100  0000  1101  1110
  C     0     D     E

Answer: xC0DE  (a classic "hex word" — useful sanity check that you grouped correctly).

E2020 Q1c — decimal 86 to 2 hex digits

86 = 0101 0110 → 5 and 6. Answer: x56

2.2  Assembly → Machine Code

Method
  1. Identify the opcode → write bits [15:12].
  2. Encode each register as a 3-bit number (R0=000 … R7=111).
  3. For immediate forms set bit 5 = 1 and write the value as a signed 2's-complement field of the right width.
  4. For branches/loads, the offset is (target address) − (address of next instruction, i.e. PC after increment), stored signed.
  5. Group the 16 bits into 4 nibbles → hex.
F2024 Q1a — assemble the program at x3000
      .ORIG x3000
      ADD R7, R2, #12      ; x3000
LOOP  BRnzp LOOP           ; x3001, branches to itself
      .END

ADD R7, R2, #12 — opcode 0001, DR=R7=111, SR1=R2=010, imm bit=1, imm5 = 12 = 01100:

0001 111 010 1 01100  =  0001 1110 1010 1100  =  x1EAC

BRnzp LOOP — opcode 0000, nzp=111. It sits at x3001; PC after fetch = x3002; target = x3001; offset = x3001 − x3002 = −1 = 111111111 (9-bit):

0000 111 111111111  =  0000 1111 1111 1111  =  x0FFF

Answers: x1EAC   x0FFF

2.3  Symbol Tables

Method Start the address counter at the .ORIG value. Each real instruction and each .FILL/.STRINGZ word advances it by 1 (a .STRINGZ consumes one word per character plus one for the terminating \0). A label takes the address of the line it is attached to. .ORIG/.END consume nothing.

2.4  The imm5 Limit (a favourite trap)

Constraint The immediate in ADD/AND is a 5-bit signed field, so it only spans −16 … +15. ADD R0, R0, #37 is therefore illegal.
F2023 Q1d — add 37 to R0 correctly

Option A — chain several legal adds (15+15+7 = 37):

ADD R0, R0, #15
ADD R0, R0, #15
ADD R0, R0, #7

Option B — load the constant from memory (works for any size, but uses an extra register):

      LD  R1, A
      ADD R0, R0, R1
A     .FILL #37

Option B is the only practical one for large constants such as 10000.

3  Reading & Reverse-Engineering LC-3

General approach
  1. Decode line-by-line using the format table; write a plain comment on each line saying what it does to which register/memory cell.
  2. Name the registers after the variables they seem to hold (a counter, a pointer, an accumulator).
  3. Find the loop: where does a branch jump backwards? What is the loop condition and what changes each pass?
  4. State the net effect in one sentence, then verify with the worked example values given in the question.

3.1  Sum 1..N F2021 Q1

AND R0,R0,#0   ; R0 = 0   (accumulator)
LD  R1, val    ; R1 = 10  (counter, from memory)
loop BRnz done ; stop when R1 <= 0
ADD R0,R0,R1   ; R0 += R1
ADD R1,R1,#-1  ; R1--
BRnzp loop
done TRAP x25  ; HALT
val .FILL x000A ; = 10

What it does: R0 accumulates 10+9+…+1. The program computes in R0 the sum of all integers from 1 to N, where N is read from val. With N=10 the result is 55.

3.2  Multiplication Table F2022 Q1

x3000 LEA R4, xFF   ; R4 <- x3100 (store pointer)
x3001 ADD R2, R0,#0 ; R2 <- R0   (running multiple)
x3002 NOT R3, R1
x3003 ADD R3,R3,#1  ; R3 <- -R1
x3004 L STR R2,R4,#0; M[R4] <- R2
x3005 ADD R4,R4,#1  ; advance pointer
x3006 ADD R2,R2,R0  ; R2 += R0 (next multiple)
x3007 ADD R5,R3,R2  ; R5 = R2 - R1
x3008 BRn L         ; loop while R2 < R1
x3009 HALT

Inputs: R0 and R1. What it does: stores the multiplication table of R0 in memory from x3100, while each stored value is still less than R1. E.g. R0=4, R1=17 → stores 4, 8, 12, 16.

Trick to remember NOT Rx followed by ADD Rx,Rx,#1 is the idiom for negation (Rx ← −Rx). Adding a negated value is how LC-3 does subtraction.

3.3  Assembly → C Function E2020 Q2

Method for stack-based functions Recognise the prologue/epilogue. ADD R6,R6,#-k then STR R7/STR R5 is the standard prologue (save return address & old frame pointer, set new frame pointer R5, allocate locals). Then LDR Rx, R5, #4, #5, … read arguments (just above the bookkeeping), while LDR/STR R5,#0, #-1 touch locals. The epilogue restores R5, R7 and pops everything.

Decoding the body: it loads argument x (R0) and pointer argument y (R2), computes R1 = -(*y), then t = x - (*y) + 5, stores t, and returns t if t>0 else 0.

// equivalent C function
int func(int x, int* y){
    int t;
    t = x - (*y) + 5;
    if (t > 0)
        return t;
    else
        return 0;
}
Watch the branch sense BRnz label1 jumps to the "else" when t ≤ 0, so the fall-through path is the t > 0 case. Always translate the condition by asking "which flag values take the branch?"

4  Writing LC-3 Programs

Standard loop skeleton Almost every program here is: set a pointer + counter → at the top of the loop test the stop condition with a BR → do work → advance pointer / decrement counter → BRnzp back to top. Strings are walked until the \0 (value 0) is read.

4.1  Caesar Encryption (+5 to each ASCII) F2023 Q2

Plan Point R3 at the string. Loop: LDR a char; if it is 0 (the \0) stop; otherwise add 5, print it with OUT, advance the pointer, repeat. 
      .ORIG x3000
      LEA R3, S
L     LDR R0, R3, #0     ; load current char
      BRz H              ; \0 -> done
      ADD R0, R0, #5     ; shift ASCII by 5
      OUT                ; print char in R0
      ADD R3, R3, #1     ; next char
      BRnzp L
H     HALT
S     .STRINGZ "This is my secret message!"
      .END

Output ("This" → "Ymnx", space x20→x25 prints as %):

Ymnx%nx%r~%xjhwjy%rjxxflj&

4.2  Histogram of low nibbles F2021 Q2

Plan Two loops. Loop 1 zero-fills the 16-entry histogram (index 15 down to 0). Loop 2 walks the string: mask each char with x000F to get its low nibble, use that as an index, and increment histogram[index]. 
      .ORIG x3000
      LD  R3, inStr      ; pointer into string
      LD  R4, histogram  ; base of histogram
      AND R0, R0, #0
      LD  R5, maxindex   ; 15
loop1 BRn loop2          ; until index < 0
      ADD R6, R4, R5     ; &histogram[R5]
      STR R0, R6, #0     ; = 0
      ADD R5, R5, #-1
      BRnzp loop1
loop2 LDR R2, R3, #0     ; current char
      BRz done
      AND R1, R2, xF     ; low 4 bits
      ADD R1, R1, R4     ; &histogram[nibble]
      LDR R0, R1, #0
      ADD R0, R0, #1     ; ++
      STR R0, R1, #0
      ADD R3, R3, #1
      BRnzp loop2
done  HALT
inStr     .fill x4000
histogram .fill x5000
maxindex  .fill #15
      .end

For "test": index 4 ('t') = 2, index 3 ('s') = 1, index 5 ('e') = 1, rest 0.

4.3  Count occurrences of 3 and 4, print message E2020 Q4

Plan Walk 10 memory values. For each value test (value−3)==0 → bump counter R3; else test (value−4)==0 → bump R4. After the loop, convert each count to a printable digit by adding x30 ('0'), then print the three fixed strings interleaved with OUT of the counts. 
      .ORIG x3000
      LD  R2, AR         ; R2 -> x4400
      AND R3, R3, #0     ; count of 3s
      AND R4, R4, #0     ; count of 4s
      ADD R1, R3, #10    ; loop counter = 10
SL    BRnz MSG
      LDR R0, R2, #0
      ADD R5, R0, #-3
      BRnp T3            ; not a 3
      ADD R3, R3, #1
      BRnzp LB
T3    ADD R5, R0, #-4
      BRnp LB            ; not a 4
      ADD R4, R4, #1
LB    ADD R1, R1, #-1
      ADD R2, R2, #1
      BRnzp SL
MSG   LD  R0, AO         ; x30 = '0'
      ADD R3, R3, R0     ; count -> ASCII digit
      ADD R4, R4, R0
      LEA R0, S1
      PUTS
      ADD R0, R3, #0
      OUT
      LEA R0, S2
      PUTS
      ADD R0, R4, #0
      OUT
      LEA R0, S3
      PUTS
      HALT
AR  .FILL x4400
S1  .STRINGZ "Terningen fik "
S2  .STRINGZ " gange vaerdien 3 og "
S3  .STRINGZ " gange vaerdien 4\n"
AO  .FILL x30
      .END
Digit-to-ASCII idiom A single digit value d (0–9) is printed by adding x30 ('0') to turn it into its ASCII code, then OUT. This only works for one digit at a time.

4.4  Count decimal digits in a string F2022 Q2

Plan A char is a decimal digit iff its ASCII code is in ['0'..'9'] = [x30..x39]. Test: it is not a digit if (c − x30) < 0 OR (c − x39) > 0. Walk the string, increment R0 on each digit, stop at \0. 
      .ORIG x3000
      LEA R3, S
      AND R0, R0, #0
LOOP  LDR R2, R3, #0
      BRz DONE
      ADD R3, R3, #1
      LD  R4, ToD        ; -x30
      ADD R5, R2, R4     ; c - '0'
      BRn NOTD           ; below '0'
      ADD R5, R5, #-9    ; (c-'0') - 9
      BRp NOTD           ; above '9'
      ADD R0, R0, #1     ; it's a digit
NOTD  BRnzp LOOP
DONE  HALT
S   .STRINGZ "The prime numbers between 1 and 10 are: 2, 3, 5 and 7."
ToD .FILL x-30
      .END

Returns R0 = 7 for the example string.

5  Flowcharts

Conventions used in the exam
  • Oval = Start / Stop.
  • Rectangle = an action / assignment, written with ← (e.g. R0 ← 0). You may show both the register and its variable meaning.
  • Diamond = a decision; label the two outgoing arrows True / False.
  • Arrows show control flow; a loop is an arrow going back up to the decision.
Method — turn code into a flowchart
  1. Start oval → initialisation boxes (set up counters/pointers) in declaration order.
  2. Each BR that can fall through or jump becomes a diamond. The condition is the negation/sense of the branch.
  3. The loop body becomes the chain of action boxes between the test and the backward branch.
  4. The exit branch leads to Stop (or the next block).

Example shape — Sum 1..N (F2021 Q1a)

      ( Start )
          |
     [ R0 <- 0 ]
          |
     [ R1 <- 10 ]
          |
   <----> < R1 > 0 ? > --False--> ( Stop )
   |          | True
   |     [ R0 <- R0 + R1 ]
   |          |
   |     [ R1 <- R1 - 1 ]
   |__________|  (back up to the test)

Example shape — nested loop (F2024 Q2b)

The 2024 program is a while(x>0) with an inner do…while guarded by if(x%8==0). The flowchart has an outer decision x ≤ 0? (True → Stop), a branch x%8==0?, and an inner action chain (t←t+z; z←z+1) with its own back-edge tested by x ≥ z?. The corresponding C is in §3-style translation:

int x=15, t=0, z;
while (x > 0){
    if (x % 8 == 0){
        z = 0;
        do { t = t + z; z++; } while (x >= z);
    }
    x--;
}

6  C: Strings, Arrays & Pointers

6.1  Debugging a string reader F2023 Q3a

How to spot the bugs Read the comments to see the intended logic, then check four classic mistakes: (1) uninitialised pointer/index used before allocation, (2) assignment = where comparison == was meant inside a condition, (3) wrong logical operator, (4) returning a value through a parameter that was passed by value instead of by pointer.
BugFix
char* buffer; never allocated, and i uninitialisedchar* buffer = malloc(100*sizeof(char)); and int i = 0;
if ((c=' ') && (c='\t')) — assignments, and && can never both holdif ((c==' ') || (c=='\t'))
word counting logic increments on every non-space, not once per wordonly count when entering a word: if(!wordStarted){wordStarted=1;(*nrWords)++;}
nrWords passed by value, so caller never sees the countchange signature to char* readString(int* nrWords) and use *nrWords
char* readString(int* nrWords){
    char c; int i = 0;
    char* buffer = malloc(100*sizeof(char));
    char wordStarted = 0;
    printf("Write an input string:");
    *nrWords = 0;
    while ((c=getchar()) != '\n'){
        buffer[i++] = c;
        if (c==' ' || c=='\t'){
            if (wordStarted) wordStarted = 0;   // end of a word
        } else if (!wordStarted){
            wordStarted = 1;
            (*nrWords)++;                        // new word started
        }
    }
    buffer[i] = '\0';
    return buffer;
}
Return-by-pointer rule C passes arguments by value. To let a function return an extra value through an argument, pass a pointer to the caller's variable and write through it (*nrWords = …). The call becomes readString(&nrWords).

6.2  Find first-letter positions F2023 Q3b

Plan Walk the string with index i. Track wordStarted. Each time you transition from whitespace into a non-space character you have found a word start — record i into the next slot of posArray (slot 0 already holds the word count, so start writing at index 1). 
void firstLettersPositions(char* string, int* posArray){
    int i = 0, wordIndex = 1, c;
    char wordStarted = 0;
    while ((c = string[i]) != '\0'){
        if (c==' ' || c=='\t'){
            if (wordStarted) wordStarted = 0;
        } else if (!wordStarted){
            wordStarted = 1;
            posArray[wordIndex++] = i;   // position of this word's first letter
        }
        i++;
    }
}

For " One short example" → posArray = [3, 2, 6, 12] (slot 0 = 3 words; note two leading spaces).

6.3  Print each word with its position F2023 Q3c

Plan posArray[0] is the word count. For each i from 1..count: jump to j = posArray[i] in the string and print characters until a space, tab, or \0; then print the position. 
void showPosArray(char* string, int* posArray){
    int i = 1, j; char c;
    printf("First letters in the string have the following positions:\n");
    while (i <= posArray[0]){
        printf("The word ");
        j = posArray[i];
        while ((c = string[j++]) != ' ' && c != '\t' && c != '\0')
            printf("%c", c);
        printf(" starts at string position %d\n", posArray[i]);
        i++;
    }
}

6.4  Allocating a struct & its string E2020 Q3

Pointer size A pointer holds an address. If addresses are 32-bit, sizeof(z) for any pointer z is 4 bytes — regardless of how big the struct it points to is.
Stack vs heap To allocate on the runtime stack, declare a normal local variable / array and take its address. To allocate on the heap, call malloc (and remember the room for the \0 of any string). 
int main(){
    struct S1 { int a; char b; char* c; } *z;

    // Missing code 1: build on the stack, point z at it
    char s[] = "Pikaboo";
    struct S1 aa = {5, 'z', s};
    z = &aa;

    // Missing code 2: mutate through z, new string on the heap
    z->a = 7;
    z->b = 'b';
    z->c = (char*)malloc(10*sizeof(char));
    z->c[0]='O'; z->c[1]='K'; z->c[2]='\0';
    return 0;
}

6.5  Arrays of strings (char**) F2021 Q3a

Key insight strings[0][0]='H' dereferences strings twice, so strings must point at an array of char*, and strings[0] must point at writable storage. The fix is to give those pointers real backing storage — without editing Jakob's fixed lines. 
char** strings;
char string[] = "Hola";
char* strArray[3];

char str0[3];          // L1: writable backing for word 0
strings = strArray;    // L2: strings now points at the array of char*
strArray[0] = str0;    // L3: slot 0 points at writable memory

strings[0][0]='H'; strings[0][1]='i'; strings[0][2]='\0';
strings[1] = "Hello";  // string literal

strArray[2] = string;  // L4: slot 2 -> the "Hola" array
Why the original crashed char** strings; was used uninitialised — writing through strings[0][0] dereferences a garbage pointer. Always make a pointer point at real storage before writing through it.

7  C: Linked Lists

The node and the three motions A node is struct Node{ int data; struct Node* next; };. Nearly every list task is built from three moves: walk (cur = cur->next until NULL), splice out (prev->next = cur->next), and splice in / re-link (set a node's next to a new target). Keep a prev pointer whenever you might delete.

7.1  Find the middle — slow/fast pointers F2024 Q3

Plan Advance slow by one and fast by two each step. When fast reaches the end, slow is at the middle. For even length this lands on the second of the two middle nodes, exactly as required. 
struct Node* findMiddle(struct Node* head){
    struct Node* slow = head;
    struct Node* fast = head;
    while (fast != NULL && fast->next != NULL){
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}

17→2→9→6→4 returns 9; 17→2→9→6→4→1 returns 6.

7.2  Append to the end F2021 Q4a

Plan Walk to the last node (keeping previousNode). Make the new node, set its next=NULL. If the list was empty, it becomes header; otherwise link it after the old last node. 
void append_node(int val){
    node* currentNode = header;
    node* previousNode = NULL;
    node* newNode = (node*)malloc(sizeof(node));
    while (currentNode){ previousNode = currentNode; currentNode = currentNode->next; }
    newNode->val = val;
    newNode->next = NULL;
    if (previousNode) previousNode->next = newNode;
    else              header = newNode;
}

7.3  Remove duplicates F2021 Q4b/c

Plan (one pass) Given a startNode, scan everything after it; whenever a later node has the same val, splice it out via previousNode->next = currentNode->next (and do not advance previousNode). To clean the whole list, call this for every node in turn. 
void remove_duplicates(node* startNode){
    node *currentNode, *previousNode;
    if (startNode){
        currentNode = startNode->next;
        previousNode = startNode;
    } else return;
    while (currentNode){
        if (currentNode->val == startNode->val)
            previousNode->next = currentNode->next; // splice out
        else
            previousNode = currentNode;
        currentNode = currentNode->next;
    }
}
void remove_all_duplicates(){
    node* currentNode = header;
    while (currentNode){
        remove_duplicates(currentNode);
        currentNode = currentNode->next;
    }
}

7.4  Reverse the list F2021 Q4d

Plan — three-pointer reversal Walk the list, and for each node remember its next before overwriting it; point the node back at the new head; advance the new head to this node. Finally update header. 
void reverse_list(){
    node* current = header;
    node* newHeader = NULL;
    node* next;
    while (current){
        next = current->next;       // save the rest
        current->next = newHeader;   // flip the link
        newHeader = current;        // grow reversed prefix
        current = next;             // move on
    }
    header = newHeader;
}

7.5  Strings as linked lists of chars F2022 Q3

Two node types: charNode{char c; charNode* next;} for one string, and stringNode{charNode* header; stringNode* next;} for a list of strings.

Read a string from the keyboard (b)

struct charNode* initializeStringAsLinkedList(){
    char c; struct charNode *n, *current, *header = NULL;
    printf("Input a string:");
    current = header;
    c = getchar();
    while (c != '\n'){
        n = malloc(sizeof(struct charNode));
        n->c = c; n->next = NULL;
        if (!current) header = n;       // first char
        else current->next = n;         // link after previous
        current = n;
        c = getchar();
    }
    return header;
}

Count words (c)

IdeaTrack a beforeAWord flag; count a word only on the first non-space after spaces.
int numberOfWords(struct charNode* string){
    int nr = 0, beforeAWord = 1;
    struct charNode* current = string;
    while (current){
        if (current->c == ' ') beforeAWord = 1;
        else if (beforeAWord){ beforeAWord = 0; nr++; }
        current = current->next;
    }
    return nr;
}

Replace letter at 1-based position (d)

void replaceLetterAtPos(struct charNode* string, unsigned int pos, char letter){
    struct charNode* current = string; int i = 1;
    while (current && (i < pos)){ current = current->next; i++; }
    if (current && pos) current->c = letter;  // pos==0 is invalid -> no change
}

To upper case — build a new list (e)

IdeaCopy each node into a fresh list; if a char is in 'a'..'z', subtract 0x20 to get its capital.
struct charNode* stringToUpperCase(struct charNode* string){
    struct charNode *current = string, *stringOut = NULL, *prevCharNode = NULL, *newCharNode;
    char c;
    while (current){
        newCharNode = malloc(sizeof(struct charNode));
        newCharNode->next = NULL;
        if (!prevCharNode) stringOut = newCharNode;
        else prevCharNode->next = newCharNode;
        c = current->c;
        if (c >= 'a' && c <= 'z') newCharNode->c = c - 0x20;
        else newCharNode->c = c;
        prevCharNode = newCharNode;
        current = current->next;
    }
    return stringOut;
}

Split on a separator into a list of strings (f)

IdeaWalk char by char. On a separator, mark newString=1 and terminate the current sub-string by setting the previous node's next=NULL. On the first char of a new word, allocate a stringNode pointing at that char and append it to the list of strings.
struct stringNode* split(struct charNode* string, char separator){
    struct stringNode *header = NULL, *last = NULL, *lnode;
    struct charNode *current = string, *prev = NULL;
    int newString = 1;
    while (current != NULL){
        if (current->c == separator){
            newString = 1;
            if (prev) prev->next = NULL;     // cut the chain here
        } else if (newString == 1){
            lnode = malloc(sizeof(struct stringNode));
            if (last) last->next = lnode; else { header = lnode; last = header; }
            lnode->header = current; lnode->next = NULL;
            last = lnode; newString = 0;
        }
        prev = current;
        current = current->next;
    }
    return header;
}

8  The Runtime Stack

LC-3 conventions (memorise)
  • int and pointer = 1 word (16 bit); memory is word-addressable.
  • The stack grows downward (toward lower addresses). R6 = stack pointer, R5 = frame pointer.
  • An activation record, from high to low address, holds: RV (return value), RA (return address), DL (dynamic link = caller's frame pointer), then the function's local variables.
  • Locals are placed in the same order they are declared (first declared = highest address).
  • Function arguments are pushed by the caller right-to-left, so they sit just above the callee's RV/RA/DL.
Method — draw an activation record
  1. Write the addresses downward from where R6 starts ("stack empty" value) — leave the top 3 words for RV, RA, DL of the first frame.
  2. Lay out each local in declaration order (arrays occupy consecutive words; a struct's members occupy consecutive words in declaration order).
  3. Fill initial values, then play the code line by line, updating only the cells each statement touches. Track what every pointer currently points at (write the target address).
  4. Use arrows old -> new in a cell to show its history; the last value is the state "just before return".

Branch sense

  • flags n/z/p set from the last value written to a register.
  • BRn taken if <0; BRz if =0; BRp if >0; combine letters to OR them.
  • BRnzp = unconditional.

R6 = SP (top, low addr). R5 = FP. Stack grows down. int/ptr = 1 word.

C pointer cheats

  • sizeof(any pointer) = address width, independent of target.
  • return extra values by passing &var and writing *ptr=….
  • p[i] ≡ *(p+i); pointer arithmetic steps by element size.
  • always allocate (stack var or malloc) before writing through a pointer.
  • strings need room for the trailing \0.

Linked-list moves

  • walk: cur=cur->next until NULL
  • delete: prev->next=cur->next
  • insert after: n->next=p->next; p->next=n;
  • reverse: save next, flip link, advance head
  • middle: slow+1 / fast+2
